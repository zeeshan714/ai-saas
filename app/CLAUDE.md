# Project Guide & Context

## Tech Stack
- **Framework:** Next.js (App Router, TypeScript)
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Database/Auth:** Supabase (Layer 2)

## Rules for AI Assistant
1. Always maintain the App Router folder structure (`app/`).
2. Keep component logic clean and use reusable components inside designated folders.
3. Check for TypeScript types before writing complex state logic.
4. Keep `CLAUDE.md` short and updated (under 200 lines).

## Common Commands
- `npm run dev` - Start local development server
- `npm run build` - Build the project for production
- `npm run lint` - Run ESLint checks
